# Дом и дача — история покупок

Интерактивный дашборд на Vue 3 и D3.js. Приложение работает без серверной части и подготовлено для GitHub Pages, в том числе в подпапке репозитория.

## Локальный запуск

```bash
npm install
npm run dev
```

Перед сборкой данных можно повторно выполнить `npm run prepare:data`. Скрипт читает исходный `.xlsx`, оставляет только доставленные позиции и создаёт `src/data/purchases.json`. В публичном JSON удалены адреса и точное время, а номера заказов заменены локальными идентификаторами.

## Сборка и публикация

```bash
npm run build
npm run preview
```

`vite.config.js` использует относительный `base: './'`, поэтому результат из `dist/` корректно работает в подпапке GitHub Pages.

Для публикации в этом репозитории:

1. Откройте **Settings → Pages → Build and deployment** и выберите **Source: GitHub Actions**.
2. Отправьте изменения в ветку `main`. Workflow `.github/workflows/deploy.yml` установит зависимости, соберёт приложение и опубликует только содержимое `dist/`.
3. Дождитесь успешного завершения **Deploy dashboard to GitHub Pages** на вкладке **Actions**. Повторную публикацию можно запустить вручную через **Run workflow**.

Сайт: [peshexodka.github.io/week4_CU/](https://peshexodka.github.io/week4_CU/).

Не используйте **Deploy from a branch → main → / (root)**: в корне лежит исходный `index.html` с подключением `/src/main.js`, а GitHub Pages не выполняет сборку Vite. Такой вариант даёт пустую страницу. Собирать приложение нужно до публикации; добавлять `dist/` в Git не требуется.

## Проверка данных

Итоги после подготовки данных: 944 доставленных заказа, 1 278 791 ₽ общих трат, 1 236 462 ₽ трат на товары, 5 244 единицы, 25 543 ₽ экономии и 2,02% взвешенной скидки на товары. Услуги «Доставка» и «Упаковка» входят в общие траты, но исключены из количества товаров и рейтинга.

Изображений из архива `Items` в исходных материалах нет, поэтому товары отображаются с нейтральной заглушкой.
